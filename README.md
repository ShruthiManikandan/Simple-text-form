# Real-Time Character Counter

## 📌 Project Description

This project is a simple Real-Time Character Counter developed using HTML, CSS, and JavaScript. It allows users to type a message in a text area while displaying the number of characters entered and the number of characters remaining. The application enforces a maximum character limit of 200 characters and displays a warning message when the limit is reached.

## ✨ Features

* **Text Area:** Provides a text area where users can type their messages.
* **Character Limit:** Sets a maximum limit of 200 characters.
* **Real-Time Counter:** Updates the character count dynamically as the user types.
* **Remaining Characters:** Displays the number of characters remaining.
* **Input Event Listener:** Uses JavaScript to track user input and update the counter instantly.
* **Limit Enforcement:** Prevents users from entering more than 200 characters.
* **Warning Message:** Displays a warning when the character limit is reached.

## 🛠️ Technologies Used

* **HTML5** – Creates the text area and counter elements.
* **CSS3** – Styles the text area, counter, and warning messages.
* **JavaScript** – Implements real-time character counting and character limit validation.

## ⚙️ How It Works

1. The user types a message into the text area.
2. JavaScript listens for input events and updates the character count in real time.
3. The application displays the number of characters typed and the remaining characters allowed.
4. The maximum character limit is set to 200 characters.
5. When the limit is reached, a warning message is displayed, and further typing is prevented.

**Example Output:**

* Characters typed: 150
* Characters remaining: 50
* Maximum limit: 200 characters

## 🚀 How to Run the Project

1. Clone or download the repository.
2. Open the project folder.
3. Open the `index.html` file in any web browser.
4. Type a message into the text area and observe the character counter.

## 🎯 Project Objective

The objective of this project is to understand JavaScript event handling, real-time DOM updates, and input validation while developing an interactive and user-friendly text area.
